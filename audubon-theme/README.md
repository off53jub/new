# Studio Audubon Customizations - 設置手順

このフォルダ（`audubon-theme/`）の中身を、現在使用中のWordPressテーマフォルダ
（例: `wp-content/themes/お使いのテーマ名/`）にそのままアップロードしてください。

## 含まれるファイル

| ファイル | 役割 | 設置場所 |
|---|---|---|
| `audubon-customizations.php` | メイン機能（メタボックス・ショートコード等） | テーマ直下 |
| `single-actor.php` | アクター詳細ページ用テンプレート | テーマ直下 |
| `single-news_list.php` | ニュース詳細ページ用テンプレート | テーマ直下 |
| `archive-news_list.php` | ニュース一覧ページ用テンプレート | テーマ直下 |
| `template-works.php` | Works固定ページ用テンプレート（A4ポスター一覧） | テーマ直下 |
| `assets/css/audubon.css` | 専用CSS | `assets/css/` |
| `assets/js/audubon-banner.js` | スライダーJS | `assets/js/` |

## 設置手順（5分）

### 1. ファイルをアップロード
FTP / WordPress管理画面 / cPanel等で、上記ファイル一式を **テーマフォルダ直下** にアップロードします。
（例: `wp-content/themes/audubon/` の中に `audubon-customizations.php` が並ぶ状態）

`assets/` フォルダはそのままアップロードしてフォルダごと残してください。

### 2. functions.php に1行追加
テーマの `functions.php` の末尾（`?>` がある場合はその直前）に以下の1行を追加します。

```php
require_once get_stylesheet_directory() . '/audubon-customizations.php';
```

これで全機能が有効になります。

### 3. パーマリンクの再保存
WordPress管理画面 → **設定 > パーマリンク設定** を開いて「変更を保存」を押すだけでOK
（リライトルール再生成のため）。

## 使い方

### アクターページ（CPT: `actor`）
- アクター編集画面に「アクター追加情報」が追加されています
  - **プロフィールPDF**: メディアライブラリからPDFを選択
  - **最新の出演（ニュース記事）**: 自動取得 / 手動指定
- アクター詳細ページに「最新の出演リンク」と「PDFダウンロードボタン」が自動表示されます

### ニュース（CPT: `news_list`）
- ニュース編集画面の右サイドに「放映日時・出演アクター」が追加されています
  - **放映日時（フリーテキスト）**: 例 `2025年8月13日(水)21:00〜` `毎週土曜` `公開中` など自由記述
  - **並び替え用日付**: 一覧の並び順を制御するための任意の日付
  - **出演アクター**: アクターを複数紐付け
- ニュース一覧・詳細ページでは投稿の作成日ではなく**フリーテキストの放映日時**が表示されます

### スライド（CPT: `slides`）の体裁変更
- 既存のスライド編集画面に「ポスター下に表示するテキスト」「リンク先URL」が追加されます
- 新しい体裁で表示したい場所に下記ショートコードを貼ってください：

```
[audubon_slides]
```

→ A4ポスター3分割の自動スライダーで表示されます。
**既存のスライド表示そのものには影響しません。**

### Works（通常投稿）の表示
通常投稿をWorksとしてA4ポスター比率で表示します。

**方法A: 固定ページに専用テンプレートを割り当てる**
1. 管理画面 → 固定ページ → 新規追加 で「Works」ページを作成
2. 右サイドバーの「テンプレート」で **「Works (A4ポスター一覧)」** を選択
3. 公開

**方法B: 任意のページにショートコードで貼る**
```
[audubon_works]
```

オプション:
- `columns="3"`（カラム数: 2 / 3 / 4）
- `category="works"`（カテゴリで絞り込み）
- `limit="12"`（表示件数）

例:
```
[audubon_works columns="4" category="works" limit="12"]
```

## ショートコード一覧

| ショートコード | 用途 |
|---|---|
| `[audubon_slides]` | スライドをA4ポスター3分割の自動スライダーで表示 |
| `[audubon_works]` | 通常投稿をA4ポスター比率の静的グリッドで表示 |
| `[audubon_actor_links]` | アクターページの「最新の出演 / PDF」リンクブロック |
| `[audubon_news_date]` | ニュース記事の放映日時（フリーテキスト）を表示 |

## アンインストール

`functions.php` に追加した1行を削除し、テーマフォルダから本パッケージのファイルを削除すれば元に戻ります。
編集画面で入力したデータ（PDF・放映日時等）はDBに残るので、再導入すれば復元されます。

## 動作要件

- WordPress 6.0 以降
- PHP 7.4 以降
- 既存のCPT `actor` / `news_list` / `slides` がテーマまたはプラグインで登録されていること
