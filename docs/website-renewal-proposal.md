## 1. 要約（このページだけでも読んでください）

**サイトの中身（ニュース更新）は今も活発に動いていますが、器（テーマ＝サイトの土台）は2020年頃の制作のまま止まっており、「商機の取りこぼし」「信頼性を損なう細部」「放置すると危ないリスク」の3つが積み上がっています。**

- **費用はほぼゼロで改修できます。** 外部発注なら数十万円規模の内容ですが、改修版テーマはすでに4バージョン（03〜06）完成済みで、残りは統合・仕上げと無料プラグインの導入だけです。
- **本番サイトを壊すリスクなしに試せます。** 現行テーマを消さずに横に並べてインストールし、管理画面のワンクリックで切替・切り戻しできます。着手前にフルバックアップも取ります。
- **今やる理由があります。** プレスリリース済みの新事業「演劇部」は直近ワークショップの申込締切が**7月31日**ですが、公式サイトに演劇部のページ（受け皿・申込導線）がありません。まずここから2週間以内に公開できます。

## 2. なぜ今、改修が必要か（現状の課題）

### A. 商機を取りこぼしている

| # | 課題 | 何が起きているか |
|---|------|------------------|
| A-1 | **問い合わせへの導線が無い** | ヘッダー・フッター・俳優ページのどこにも「お問い合わせ」リンクが無く、電話番号もスマホからタップ発信できないただの文字。キャスティング担当者が俳優のページを見て「この人に頼みたい」と思った瞬間の行き先がない |
| A-2 | **SNSでシェアされても画像が出ない** | OGP（シェア時にタイトル・写真・説明文のカードを出す仕組み）が未実装。X・LINE・Facebookで公演情報を共有しても素のURLだけが表示され、拡散力を大きく損なっている。フッターのSNSアイコンもリンク先未設定（押しても何も起きない） |
| A-3 | **俳優情報の「一次情報」が公式サイトに無い** | 「（俳優名） プロフィール」で検索するとWikipedia・チケットぴあ・ファンサイトが上位に来て、公式の俳優ページが埋もれる。経歴・出演実績・宣材PDF・本人SNSリンクの充実度で第三者サイトに負けている |
| A-4 | **俳優一覧が24名で打ち切られる設定** | 一覧ページは24名固定でページ送りが無く、所属が25名を超えると以降の俳優が一覧のどこからも辿れなくなる（現時点の所属人数の確認が必要） |
| A-5 | **新事業「演劇部」の受け皿が無い** | プレスリリース配信済み・申込締切7/31のワークショップが進行中なのに、公式サイト内に演劇部の常設ページ・申込導線・過去回アーカイブが無い（発信はX頼み） |
| A-6 | **グッズストアへの導線が無い** | デザインストア（外部サービス）への紹介・送客ページが公式サイトに無い |

### B. 会社の信頼性を損なう細部

- コピーライトが「**© 2018**」のまま固定 → 「手入れされていないサイト」の印象
- ブラウザタブのアイコン（favicon）が未設定
- 俳優写真の代替テキストが「...」のまま（画像検索・読み上げソフトに内容が伝わらない）
- テーマ内に**制作途中の試作HTMLが残置**され、URLを直接叩くと閲覧可能。その中に**現在と食い違う旧住所（南麻布）入りの会社概要**やダミー挨拶文が含まれる
- 検索結果に新旧2種類のサイト名表記、http://のままのページ、同一俳優の重複URLが混在

### C. 放置すると危ないリスク

- **旧制作会社の開発サーバーに画像を依存**: Worksページのバナー画像が「studio-audubon.gridrocks.com」（制作会社 grid Inc. の開発サーバーとみられるドメイン）から直接読み込まれている。先方のサーバー停止・ドメイン解約で画像が突然消え、最悪の場合ドメインを第三者に取得されると公式サイト上に任意の画像を表示される入り口になる
- **既知の欠陥が公表済みの古い部品を使用**: jQuery 3.4.1（2019年版。CVE-2020-11022/11023 というXSS欠陥が修正される前の版）、Bootstrap は CSS 4.1.3 と JS 4.3.0 でバージョン不一致のまま全ページで読み込み
- **表示が遅い構造**: デザインファイルに毎回異なる時刻が付与されブラウザキャッシュが完全無効（毎アクセスで再ダウンロード）。約21個のファイルが画面描画をブロックしながら4つの外部CDNから直列読み込み。俳優一覧は縮小画像の設定ミスで原寸写真（数百KB×24枚）をそのまま読み込み
- **プラグイン1つの停止でトップ・俳優ページが白画面になる**構造（保険となる存在チェックが無い）
- **バックアップ体制が確認できない**: 俳優の顔写真・プロフィールという「商品情報」そのものを載せたサイトなのに、障害・改ざん時に戻せる保証が無い

> 重要な注記: 上記は本番サイトを構成するテーマのコード（このリポジトリに保存されている現行相当のコード）と、Google検索に出ている実際の結果から確認したものです。本番サーバー内の設定（プラグイン・PHP版数・バックアップの有無）は着手時の「環境診断」で確定させます。

## 4. 改修プラン（フェーズ分け）

### フェーズ0: 準備・診断（半日〜1日）※これだけでも価値があります

1. **フルバックアップの取得と復元テスト**（無料プラグイン UpdraftPlus、保存先はGoogle Drive等）→ 以後どんな作業も「戻せる」状態にする。これを成果物第1号にします
2. **環境診断**: WordPress本体・PHP・プラグイン（特にACF）の版数、バックアップの有無、フォームプラグインの状態を棚卸し
3. **現状計測**: Google Analytics 4 と Search Console を導入（無料）し、アクセス数・検索表示回数・スマホ比率の「改修前の数字」を取る → 改修の効果を後で証明するため

### フェーズ1: クイックウィン（1〜2週間で公開）

- **「演劇部」常設ページ新設**＋申込導線（7/31締切前に間に合わせる）
- 電話番号のタップ発信化、フッター・メニューに「お問い合わせ」常設
- SNSアイコンに実際のアカウントURLを設定（無い媒体はアイコン削除）
- favicon設置、© 年号の自動化
- 旧制作会社サーバー依存の画像を自社サーバーに取り込み
- http:// 混在の解消（フォント・リンク）
- 旧住所入り試作HTMLの削除（**初日に実施**）
- SEOプラグイン導入でページ別の説明文・OGP（シェア時カード）を全ページに出力
- キャッシュ無効化バグの修正（1行）＋不要ライブラリの削除

### フェーズ2: 統合テーマ「07」の投入（2〜4週間）

- 05のスマホ最適化＋06の俳優タグ機能を統合
- 基盤修正: 見出し構造（h1）、画像の代替テキスト、404ページ新設、画像縮小サイズのバグ修正、俳優一覧のページ送り、読み込みの近代化（脆弱な旧ライブラリの更新・整理）、WebP化
- ステージング（試験環境）で全ページ確認 → 更新の少ない時間帯に本番切替

### フェーズ3: コンテンツ強化（材料が揃い次第、順次）

- 俳優の定型プロフィール（生年月日・身長・特技等）と出演実績表の入力 → **宣材PDFが自動生成できる俳優ページ**へ
- 俳優ページに本人SNS・外部公式リンク欄
- ニュースに会場・放送局・チケット購入リンクの定型欄
- （ご意向次第で）俳優の条件絞り込み検索＋俳優別問い合わせボタンの復活
- ボイスサンプル掲載（朗読劇の受注導線として。主力数名から）
- グッズストア紹介ページ
- Works（公演制作実績）の会場・日程・キャスト定型化

**優先度を下げる提案**: 多言語対応は、同規模の舞台系事務所（円企画・青年座・大人計画等）でも標準ではないため今回は見送り、将来必要になったら英語1ページの追加で対応するのが費用対効果に見合います。

## 7. 安全策（サイトを止めない・壊さないために）

1. **着手前にフルバックアップ＋復元テストを実演**（これが最初の成果物）
2. **現行テーマは消さない**: 改修版は横に並べてインストールし、管理画面のワンクリックで切替。問題があれば即座に現行版へ戻せる
3. **正直な注記 — 切替で「戻らない」もの**: メニュー割当等はテーマ切替時に再設定が必要な場合があり、新テーマ用に入力したデータ（出演実績等）は旧テーマでは表示されません（データ自体は消えず、再切替で復元）。切替前後のチェックリスト（主要10ページの目視確認）を用意します
4. **本番切替は更新の少ない曜日・時間帯に実施**し、事前にステージングで全機能を確認
5. **法務・権利面は勝手に進めません**: ポスター画像の掲載許諾、俳優情報の公開範囲、プライバシーポリシーは5-4の確認リストに沿ってご判断いただいてから反映します
