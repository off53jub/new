# Studio Audubon WordPress カスタマイズ

studio-audubon.jp の既存テーマ `studio_audubon_02` をベースに、機能拡張を段階的に重ねたカスタムテーマ群です。

## バージョン一覧

| バージョン | 内容 | ZIP |
|---|---|---|
| 02 | 既存（オリジナル） | – |
| 03 | アクターPDF・ニュースのフリーテキスト日時・スライダー(A4×3) など | [studio_audubon_03.zip](./studio_audubon_03.zip) |
| 04 | TOPICSカードスライダー・スプラッシュ画面・モバイル最適化 など | [studio_audubon_04.zip](./studio_audubon_04.zip) |
| 05 | アクター絞り込み・出演実績の構造化・問い合わせCTA・Pickup動的化・印刷PDF最適化 | [studio_audubon_05.zip](./studio_audubon_05.zip) |

各バージョンは `wp-content/themes/` に**並立してインストールでき**、外観 > テーマ で切替可能です。

## studio_audubon_05 で追加された機能

### A-1 アクター絞り込み（性別 / 年代 / ジャンル / 得意分野）
- 4つのタクソノミーをアクターに付与（管理画面から選択）
- `page-actor.php` 上部にフィルターUIが自動表示
- 初期タームを自動投入（10代-60代以上、舞台/映画/TV/CM/朗読 等）

### A-3 出演実績の構造化
- アクター編集画面に「出演実績（構造化）」メタボックス
- 媒体／作品名／役名／演出・監督／公開年／関連リンク を項目別に登録
- アクター詳細ページで媒体ごとにグルーピング表示

### A-4 キャスティング問い合わせ動線
- アクター詳細ページに「**◯◯ についてお問い合わせ**」ボタン
- `/contact/?actor=◯◯` へ遷移（フォーム側でアクター名を自動入力するように改修可能）

### B-2 Pickup動的化
- `audubon_pickup` CPT を追加
- 管理画面 > Pickup から自由に追加・並び替え
- アイキャッチ画像 / YouTube埋込（URLから自動変換可）/ リンク先 を設定
- 0件の場合は既存ACFフィールドの表示にフォールバック（破壊的でない）

### B-6 アクターをジャンルで分類
- A-1の「ジャンル」タクソノミーで実現
- 俳優 / 声優 / モデル / 文化人 / タレント などを分類可能

### C-5 印刷PDF（プロフィールPDF保存）の最適化
- A4ポートレート、余白12-14mm 指定
- 名前を 22pt で大きく、肩書きを下に配置
- 出演実績テーブルが印刷時にコンパクトに整形
- フッターに `Studio Audubon | https://studio-audubon.jp/` 自動付与

### F-2 全画像の遅延読み込み
- WP標準の lazy load を有効化
- the_content フィルタで `loading="lazy"` 未付与の `<img>` に補完
- テーマテンプレートの `<img>` にも明示付与

## 別途プラグインで対応が望ましい項目

### H-2 自動バックアップ（推奨プラグイン）

**UpdraftPlus**（無料・国内シェア多数）:

1. プラグイン > 新規追加 > 「UpdraftPlus」検索
2. インストール&有効化
3. 設定 > UpdraftPlus Backups
4. 「バックアップスケジュール」を **日次** または **週次** に
5. 保存先（Google Drive / Dropbox 等）を連携
6. 「今すぐバックアップ」で初回バックアップ実行

→ 障害時にワンクリック復元できます。サーバ移転時にも便利。

### F-1 画像の WebP 自動変換（推奨プラグイン）

**EWWW Image Optimizer** または **ShortPixel Image Optimizer**:

1. プラグイン > 新規追加 > いずれかを検索
2. インストール&有効化
3. 既存メディアを一括最適化（バッチ処理）
4. 新規アップロード時も自動でWebP生成

→ ファイルサイズが平均30-50%削減。表示速度が大幅に向上します。
PHP 7.4以上で動作。古いPHPバージョンの場合は手動でWebP変換ツール（[Squoosh](https://squoosh.app)等）を使う方法もあります。

## 適用方法（共通）

1. `studio_audubon_05.zip` をダウンロード&解凍
2. 解凍した `studio_audubon_05` フォルダを `wp-content/themes/` にアップロード
   （既存の 02 / 03 / 04 と並立）
3. WordPress管理画面 > **外観 > テーマ** で「studio_audubon 05」を有効化
4. 設定 > **パーマリンク設定** で「変更を保存」（タクソノミーURL生成のため必須）
5. 必要に応じて:
   - アクターに「性別」「年代」「ジャンル」「得意分野」を設定
   - 出演実績を構造化フォームで登録
   - Pickup CPT に項目を追加（既存のACFバナー2枠を使い続ける場合は0件のまま）
6. 動作確認 → 問題なければ運用継続。問題があれば外観 > テーマで04などに戻す

## ロールバック

外観 > テーマ で `studio_audubon_04` 等を有効化するだけ。
入力した05専用データ（タクソノミー紐付け・出演実績・Pickup）はDBに残るため、再度05を有効化すれば復元されます。
